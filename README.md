# 📊 Corporate Financial Health & Bankruptcy Risk Analysis

**A Financial Analytics project using SQL Server and Power BI to analyze corporate financial performance, evaluate financial risk indicators, and explore bankruptcy risk patterns.**

---

## 📌 Project Overview

Financial health is an important factor in understanding a company's stability and long-term performance.

This project analyzes corporate financial data across different countries, industries, and years to examine financial indicators such as revenue, profit margin, debt ratio, cash flow, liquidity, credit ratings, and bankruptcy risk scores.

SQL Server is used for data exploration and analysis, while Power BI is used to create an interactive dashboard for presenting financial insights.

## 🎯 Project Objectives

- Analyze corporate financial performance across different industries and countries.
- Examine revenue, profitability, debt and liquidity indicators.
- Evaluate bankruptcy risk scores and default probabilities.
- Identify companies with higher financial risk.
- Compare financial risk patterns across industries and countries.
- Visualize financial performance and risk indicators using Power BI.

## 📂 Dataset Overview

The dataset contains corporate financial information across multiple years.

| Dataset Details | Count |
|---|---:|
| Total Records | 288,131 |
| Unique Companies | 28,000 |
| Countries | 30 |
| Industries | 15 |
| Time Period | 2005–2035 |
| Missing Values | 0 |

### Important Dataset Columns

- **Company ID:** Unique company identifier.
- **Country:** Country where the company operates.
- **Industry:** Business industry classification.
- **Revenue:** Company revenue.
- **Profit Margin:** Profitability indicator.
- **Debt Ratio:** Measures the company's debt level.
- **Cash Flow:** Cash generated or used by the business.
- **Liquidity Ratio:** Indicates the company's ability to meet short-term obligations.
- **Credit Rating:** Company's creditworthiness classification.
- **Bankruptcy Risk Score:** Financial risk indicator.
- **Default Probability:** Estimated probability of default.

## 🔄 Project Workflow

### 1. Data Understanding
- Explored the dataset structure and columns.

### 2. Data Exploration & Cleaning Using SQL
- Checked total records and unique companies.

- Analyzed financial performance across different years.
- Compared revenue and profitability across industries.
- Examined debt ratios and default probabilities by country.
- Identified companies with higher bankruptcy risk scores.

- Ranked countries based on average default probability.

### 4. Power BI Dashboard
- Developed an interactive financial risk dashboard.
- Presented financial indicators through visualizations.
- Analyzed financial performance and risk patterns.
